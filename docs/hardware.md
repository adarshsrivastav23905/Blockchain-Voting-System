# Network and Wallet Requirements

This project is software-based and does not require physical hardware.

## Local Development Requirements

| Component | Requirement |
| --- | --- |
| Blockchain node | Hardhat Node |
| Wallet | MetaMask |
| RPC endpoint | `http://127.0.0.1:8545` |
| Chain ID | `31337` |
| Frontend | Browser at `http://localhost:3000` |
| Backend | Express API at `http://localhost:5000` |

## Wallet Accounts

Hardhat provides funded development accounts. Use these accounts only on the local network. Never use their public test private keys on a live network.
