# Screenshot Evidence

Store demonstration screenshots in this folder. Recommended evidence includes:

1. Dashboard with connected wallet and voting statistics
2. Admin panel
3. Candidate registration success
4. Voter registration list
5. Duplicate candidate-address validation
6. Voting started
7. Active voting page
8. Successful vote
9. Duplicate-vote prevention
10. Multiple voters using different wallets
11. Voted and not-voted participation lists
12. Voting results
13. Voting closed
14. Backend health response
15. Passing contract tests

Use descriptive names such as `01_dashboard.png`. Hide private keys, seed phrases, passwords, and unnecessary personal information.
